## Selected Work

**DRAVION** &nbsp;—&nbsp; *Agents that ship code.*<br/>
An autonomous multi-agent coding platform. You talk to a Manager Agent; it spawns worker agents in isolated Docker sandboxes that plan, write, test, run terminal commands, and commit on their own. Not an AI-assisted editor — the agents do the work.<br/>
<sub>Multi-agent orchestration · Isolated Docker sandboxes · Autonomous coding agents</sub>

**XARON** &nbsp;—&nbsp; *Private by design.*<br/>
A privacy-first home for gaming communities and creators. End-to-end encrypted DMs no one else can read, free text / voice / video channels with screen sharing, no ads or data mining, and built-in monetization at a flat 1% commission.<br/>
<sub>End-to-end encryption · Real-time voice &amp; video · Built-in payments</sub>

A cross-border marketplace connecting expats with migration offices: find a consultant, pay safely through escrow, and get your visa. Multi-language, with identity verification built in.<br/>
